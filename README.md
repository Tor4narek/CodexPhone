# Codex Phone

Прототип телефонного голосового интерфейса: SIM800L ↔ ESP32-WROOM-32 ↔ USB ↔ Windows ↔ локальные Whisper/Piper ↔ Codex CLI.

## Что готово

- Прошивка на Rust с ESP-IDF: управление SIM800L по UART, АЦП GPIO34, ЦАП GPIO25, обмен 8 кГц / 8 бит по USB-UART. Потоки Rust на ESP-IDF выполняются как задачи FreeRTOS.
- Windows-мост: фильтр телефонных номеров, приём звонка, распознавание с `whisper-cli`, текстовый запрос `codex exec`, озвучивание через Piper, обратный вызов после долгого ответа.
- Кадровый протокол с CRC и восстановлением синхронизации после повреждённого кадра.
- `make test` / `.\make.ps1 test` для проверки логики без устройства; `make prod PORT=COM3` / `.\make.ps1 prod -Port COM3` для сборки и прошивки.

## Подключение

| ESP32 | SIM800L | Назначение |
|---|---|---|
| GPIO17, UART2 TX | RXD через согласование 3,3 → 2,8 В | AT-команды |
| GPIO16, UART2 RX | TXD | ответы модема |
| GND | GND | общий потенциал |
| GPIO34, ADC1 | SPK+ и SPK− через **дифференциальный аттенюатор/аналоговый тракт** | речь абонента |
| GPIO25, DAC1 | MIC+ и MIC− через **развязку и согласование уровня микрофона** | голос агента |

Питание SIM800L — отдельный DC/DC, рассчитанный на импульсы 2 А. Не питать SIM800L от вывода ESP32. **SPK− нельзя соединять с GND, а SPK+ нельзя подключать прямо к ADC**: это дифференциальный выход усилителя. На входе ADC нужен сигнал в диапазоне 0–3,3 В со смещением около середины диапазона, защитой и ограничением амплитуды. На выходе DAC нужны разделительный конденсатор, ослабление и согласование с дифференциальным микрофонным входом SIM800L. Конкретные номиналы следует выбрать по измеренным уровням вашей платы. Встроенный ЦАП ESP32 даёт 8 бит; ожидается телефонное, а не студийное качество.

USB на обычной плате ESP32-WROOM-32 идёт через USB-UART и использует UART0. Прошивка отключает обычную консоль ESP-IDF после запуска; системные сообщения загрузчика до старта приложения возможны и игнорируются декодером. Убедитесь, что преобразователь USB-UART платы устойчив на скорости 460800 бод.

## Установка инструментов

1. Установить Rust (`rustup`), `espup`, `ldproxy`, `espflash`. Для Xtensa ESP32: `espup install --std --targets esp32 --toolchain-version 1.97.0.0 --skip-version-parse` (версия из [официальных выпусков rust-build](https://github.com/esp-rs/rust-build/releases/tag/v1.97.0.0)). Нужны также Python, Git, CMake, Ninja и зависимости сборки ESP-IDF. [Официальный шаблон esp-rs](https://github.com/esp-rs/esp-idf-template) описывает установку. Сборке под Windows может понадобиться несколько ГБ свободного места.
2. На Windows установить `whisper.cpp` с русскоязычной моделью и Piper с русским голосом. В `phone.toml` указать пути к `whisper-cli.exe`, модели Whisper, `piper.exe`, модели Piper и `codex.exe`. Скопировать `phone.toml.example` в `phone.toml`.
3. Убедиться, что `codex exec --help` запускается и Codex CLI авторизован. Прошивка и Windows-программа не используют OpenAI API-ключ для речи.
4. Выполнить `.\make.ps1 test`. Затем подключить ESP32 и выполнить `.\make.ps1 prod -Port COM3`, заменив COM3 на фактический порт. После прошивки запустить `.\make.ps1 run-host`.

## Ограничения прототипа

- Аудио пока работает по очереди: во время воспроизведения ответа перебивание голосом не обрабатывается.
- Для обратного звонка после завершения долгой задачи нужен определившийся номер (`+CLIP`) и ответ на исходящий вызов; готовый ответ проигрывается после подтверждения активного вызова через `AT+CLCC`.
- Прибор не проверен на реальной плате и аналоговом тракте. `make test` проверяет код Windows и протокол, но не подтверждает качество звука или успешность прошивки.
- SIM800L требует работающей 2G-сети и SIM-карты с голосовыми вызовами.
